Shorts Uploader

A personal publishing tool for the owner's own YouTube channels.

What it does

Shorts Uploader is a private automation used by one creator to publish short educational and entertainment videos to the creator's own YouTube channels. It prepares each video, uploads it with the YouTube Data API, and reads basic statistics (views, likes and comment counts) and comments on those same videos so the creator can see how they perform and reply.

Who can use it

Only the channel owner. It is not offered to the public, and it does not access anyone else's channel or account.

Google and YouTube data

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. See the Privacy Policy for details.

By using this tool you also agree to the YouTube Terms of Service.
